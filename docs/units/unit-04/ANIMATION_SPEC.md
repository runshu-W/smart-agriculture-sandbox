# 第四单元动画与反馈规格

## 1. 通用原则

- 场景进入 520ms 景深推近，任务光球爆散后聚成互动台；减少动态模式改为淡入和即时状态。
- 计时任务提供暂停、继续、回看和键盘操作；教学加速不删除原标准时长说明。
- 每个复杂任务至少有“场景启动→过程操作→分支反馈→结果入档”四态，禁止用一张静态选择卡替代。
- 图表、屏幕内容、计时、粒子、弹幕、光带、节点、信封和徽章均由 DOM/CSS/SVG/Canvas 驱动，素材只承载不可由代码稳定表达的环境、人物和故事镜头。

## 4. 性能与可访问性

- 背景使用 1920x1080 WebP；故事板按当前故事延迟加载；透明助手使用 Web 友好 PNG。
- 动画优先 `transform/opacity`，持续粒子数量受限；`prefers-reduced-motion` 关闭推镜、翻转和飞行但保留步骤。
- 拖放、时间线、门、终端、节点与图表选择全部提供点击/键盘等价操作；颜色反馈同时配文字和图标。
