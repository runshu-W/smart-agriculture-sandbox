# 第四单元需求规格

## 1. 单元边界

- 单元：第四单元「学会学习 终身受益」
- 需求真相源：`docs/unit_details/unit4.md`
- 核心 NPC：农小智（学习伙伴）
- 素养：职业精神、健全人格
- 主线：限时技能学习、AI 技能大比拼、行业大咖分享、学习计划与结业，共 20 个互动点。
- 支线：学习方法工具箱、数字技能闯关，共 6 个互动点。
- AI 首版采用确定性脚本、预设数据与规则反馈；不调用自由生成模型，不把模拟结果描述为真实 AI 服务。
- 原文要求三段新农人视频，但仓库无授权视频。首版提供三镜头动态故事板、播放/暂停/重播/字幕/笔记和明确“教学故事板”标识；正式视频状态为 `blocked-external`。
- 原文写数字技能竞技场有 5 扇门，但只给出初级、中级、高级 3 个正式互动；不得擅自补写紫/橙门题目，首版展示五门空间结构并只开放原文三关。

## 4. 原文问题门禁

以下问题及选项必须逐字从 `unit4.md` 录入内容常量并由测试抽查，禁止改写：任务 A 的 3 题；数据解读的 2 题；“回顾刚才两个任务的学习过程，你觉得最有效的一次学习行为是什么？”；直播的 2 个场景；时间管理自评；人机协作；AI 态度；数字工具信心；故事检测 3 题；个人感悟；学习优势；短期目标；计划信心；番茄专注度；思维导图清晰度；四象限解释；可靠信息来源；图表选择；AI 事实错误处理。

需求写“3 张数据任务卡”但只提供 2 道题；写“5 个数字技能关卡”但只提供 3 关。实现按已授权原文内容完成 2 张卡和 3 关，同时保留可见扩展槽，不自行造题。

## 5. 数据、隐私与评分

- 主线按顺序解锁，支线不阻塞结业；所有互动写入统一 `Attempt / Progress / LearningEvent / AbilitySnapshot`。
- 倒计时首版使用可验证的教学加速模式，界面明确显示原标准时长，避免 E2E 强制等待数分钟；计时和暂停行为仍采集。
- 学习计划、笔记、讨论理由、思维导图节点仅保存到 `privateContent`；教师端只显示完成率、长度、方法与聚合策略，不读取原文。
- “情绪状态、焦虑程度、内容质量”不进行未经验证的 AI 诊断；首版只记录可观察行为和自评，不给学生贴负向标签。
