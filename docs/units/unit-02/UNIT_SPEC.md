# 第二单元需求规格：认识自我 健康成长

## 1. 单元定义

- 单元编号：`U02`
- 主关卡：自我探索·心灵成长
- 教学目标：客观认识自我，学习识别、表达与调节情绪，在农业职场挫折和团队协作中形成可迁移的应对策略。
- 核心 NPC：农小智，首版采用确定性脚本、规则提示和分支点评。
- 核心素养：健全人格；辅助维度为团队协作。
- 主线场景：自我认知镜像屋、挫折模拟田野、情绪管理实验室、青春花园、成长之树。
- 支线场景：心灵树洞、情绪能量站。
- 协作方式：首版采用共享设备讨论、组长提交和异步汇总，不实现实时多人在线协作。

## 2. 心理安全与数据边界

1. “不足”统一表述为“成长空间”；所有情绪均采用非评判性反馈，不做诊断，不生成“焦虑等级”“人格缺陷”等标签。
2. 树洞原文、触发原因、身体信号和自拟应急卡内容写入 `Attempt.privateContent`，仅学生本人当前流程可见；教师端不得展示原文或个体标签。
3. 教师端只使用完成率、策略类型分布、平均心理韧性变化和团队协作聚合数据；小样本不展示可反推个体的细分结果。
4. 开放文本可跳过或改用提示词；跳过不扣分。出现明显求助意图时，界面提供校内可信任成人/辅导渠道提示，不由系统自动判断或处置。
5. 分数表示任务完成和策略练习程度，不表示心理健康优劣。

## 3. 统一事件与完成规则

每个交互至少提交 `interaction.started`、有意义操作对应的 `interaction.action`、选择题对应的 `answer.submitted` 和满足条件后的 `interaction.completed`。文本只在 `content.submitted` 记录长度、模式和不可逆引用，不在事件载荷中复制原文。

主线完成条件为 15 个主线交互全部完成；支线不阻塞单元结业。首次完成主线交互提升心理韧性，团队任务同时提升团队协作；重复体验只记录重试与策略变化，不重复累计能力值。

## 6. 数据看板要求

- 学生端：第二单元 21 个交互进度、心理韧性基线与当前值、已掌握策略、来源说明、成长树和徽章。
- 教师端：主线/支线完成率、平均心理韧性变化、挫折情境完成率、应对策略分布、团队协作聚合；禁止树洞原文和个体情绪标签。
- 数据来源统一为 `simulation`，图表从 `Progress`、`Attempt`、`LearningEvent`、`ScoreSnapshot` 查询生成。

## 7. 路由与验收

- 单元总览：`/student/unit-02`
- 交互：`/student/unit-02/[interactionId]`
- 学生成长档案：`/student/progress`
- 教师看板：`/teacher/dashboard`

验收需覆盖：主线可顺序进入、支线可独立进入；所有操作提交统一事件；刷新后进度可恢复；主线结业触发单元事件；树洞隐私不进入教师查询；桌面与窄屏无重叠；减少动态模式可完成任务。
