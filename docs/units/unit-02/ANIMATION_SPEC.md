# 第二单元动画与反馈规格

## 1. 通用约束

- 场景转场 500-900ms，使用遮罩淡入、景深位移和光带，不使用无意义整页旋转。
- 交互反馈 120-260ms，拖拽回弹 280-420ms；连续模拟使用 `requestAnimationFrame` 或 CSS 动画。
- `prefers-reduced-motion` 下取消视差、闪烁和大幅位移，保留状态切换、进度文字和完成反馈。
- 动画不得阻塞主要按钮；计时体验提供暂停，页面离开时清理定时器。
- 所有位图只承担稳定外观；波纹、指针、弹幕、数值、图表、天气、光带、粒子和生长过程由代码实现。

## 3. 时间与音效

- 调节舱每种方法 10 秒，能量站单种体验 15 秒；计时必须真实可见并可暂停。
- 首版不依赖音频文件，所有信息有完整字幕；关键落位和完成音效预留 `audioCue` 接口，缺少音频不影响理解。
- 动画帧率目标 55-60fps；低性能设备关闭背景视差和粒子，保留操作对象与数值反馈。

## 4. 视觉验收关键帧

每个场景至少截图默认、操作中、分支反馈和完成状态。重点检查镜像职业角色不被镜框遮挡、表情图标签可辨、弹幕不遮挡按钮、30/15 秒计时不引发布局抖动、成长树随数据变化、窄屏拖拽存在点击替代操作。
