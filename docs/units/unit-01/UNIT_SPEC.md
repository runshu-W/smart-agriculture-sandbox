# 第一单元需求规格：时代导航 生涯筑梦

## 1. 单元定义

- 单元编号：`U01`
- 主关卡：时代之门・农智启航
- 教学目标：破除涉农职业刻板印象，认识农业技术演进与五类智慧农业岗位，完成职业倾向测评和主岗位选择。
- 核心 NPC：农小智，首版采用确定性讲解、分支点评和规则提示。
- 主场景：元宇宙入口大厅、传统农业馆、现代农业馆、智慧农业馆、岗位体验中心、职业测评与角色卡空间。
- 支线场景：全国新农人故事馆、职业初印象墙。
- 首版设备：桌面 Chrome/Edge，最小仿真视口 1280x720。

## 2. 通用交互约束

1. 热点悬浮或键盘聚焦时显示高亮和“点击探索”，点击后依次执行演示、讲解、提问、反馈和记录。
2. 同一场馆三个互动点完成后才解锁下一场馆；恢复页面时从已保存的场馆和互动点继续。
3. 讲解支持字幕、暂停、重播和静音。回答错误允许重试一次，重试前农小智给出具体提示。
4. 简单交互使用 React 本地状态；跨场馆进度、测评和含重试的多步骤任务可使用 reducer 或 XState。
5. 交互结果必须提交统一学习事件，并直接更新 `Attempt`、`Progress` 和当前能力快照；不依赖事件回放。
6. 缺失视频等外部素材时显示明确的“素材待接入”，不得以无关选择题替代原任务。

## 3. 统一事件

首版事件至少包含：

| 事件 | 触发点 | 主要载荷 |
|---|---|---|
| `unit.entered` | 进入第一单元 | 来源入口、当前进度 |
| `interaction.started` | 首次操作互动点 | interactionId、attemptId |
| `interaction.action` | 有意义的操作结束 | action、summary，不保存逐帧坐标 |
| `narration.completed` | 讲解自然结束 | 完成率、是否重播 |
| `answer.submitted` | 提交答案 | optionId、attemptNo、correct |
| `interaction.completed` | 满足完成条件 | durationMs、score、result |
| `task.completed` | 完成任务模块 | taskId、score |
| `unit.completed` | 完成主关卡 | durationMs、score、badgeId |
| `content.submitted` | 文本/语音结果提交 | contentRef、length、mode |
| `media.progressed` | 视频进度里程碑 | mediaId、25/50/75/100、pauseCount |

## 6. M1 样板详细规格

### 6.1 状态

`ready → operating → operationComplete → narrating → question → feedback → retryQuestion|completed`

- `ready`：摇柄高亮，显示鼠标拖动和键盘方向键提示。
- `operating`：按指针绕轴角度计算角速度；有效速度阈值以上才累计时间。
- `operationComplete`：累计 10 秒后锁定操作并平滑停止滚筒。
- `narrating`：显示农小智确定性讲解；音频缺失时使用明确的同步字幕占位，不伪造已录音状态。
- `question`：选择 20/40/60/80 小时。
- `feedback`：B 为正确；错误显示 `5×800=4000，4000÷100=40` 的分步提示。
- `retryQuestion`：只允许一次重试；二次提交后完成。

### 6.2 评分规则 v1

- 完成有效摇动：40 分。
- 完整查看讲解：20 分。
- 首次答对：40 分；重试答对：30 分；两次均错但完成反馈：20 分。
- 得分直接写入当前尝试和学生成长快照。该规则标记为 `U01-TRAD-02-v1`，后续可替换但不追溯重算首版演示数据。

### 6.3 数据与看板

- 学生页显示该互动完成状态、得分、有效摇动时间和第一单元进度。
- 教师页显示班级完成人数、首次正确率、平均有效摇动时间和重试率，数据源标签为“沙盘”。
- M1 使用演示角色切换进入学生或教师视角；教师页通过刷新获取最新聚合，不要求 WebSocket。

## 7. 权限与安全

- 学生只读取自己的尝试、进度和成长快照；教师只读取所属班级聚合与学生明细。
- M1 演示切换不视为正式认证；进入学生和教师看板里程碑时必须在服务端增加会话及角色校验。
- 昵称、广告语、感悟等文本按业务内容单独保存，学习事件只保留引用和长度。
- 本单元不采集摄像头、真实语音生物特征、眼动或生理数据。

## 8. 首版验收

- 23 个编号交互均有对应定义、事件和素材条目。
- M1 在 1280x720、1440x900、1920x1080 下无遮挡，可用鼠标和键盘完成。
- 动态操作不得被静态选择题替代；没有素材的功能必须显式标记依赖状态。
- 每个里程碑通过 lint、typecheck、相关单元测试、核心 E2E 和 build。

## 9. M2-A：入口与传统农业馆闭环

本批次按以下顺序连续解锁：

1. `U01-ENTRY-01` 邀请函入口：农小智出现，邀请函展开，确认后进入传统农业馆；采集进入来源、展开完成、确认时间。
2. `U01-ERA-TRAD-01` 木犁与牛耕：牛、木犁和扶犁者沿田垄移动 15 秒，Canvas 翻土粒子与移动同步；讲解后提交观点。采集动画观看完成率、答案、重试和总停留。
3. `U01-ERA-TRAD-02` 手摇脱粒机：沿用 M1 完整互动。
4. `U01-ERA-TRAD-03` 蓑衣斗笠与节气牌：点击取下蓑衣斗笠；节气牌使用 CSS 3D 翻转，至少查看一条农谚后进入讲解和提问。采集农谚查看数量、答案、重试和停留。

完成前三项传统馆互动后，现代农业馆显示“已解锁，下一批开放”，不伪装为可用页面。M2-A 新互动继续使用统一六类学习事件；动作明细只保存摘要，不记录逐帧路径。

## 10. 第一版本实现状态

- 入口与 17 项主线互动全部实现，按入口、传统馆、现代馆、智慧馆、五岗位试岗、测评与角色卡顺序解锁。
- 六项支线互动全部实现；故事视频当前为明确标识的教学分镜预览，十条正式纪实视频继续保持 `blocked-external`，不伪装为已交付原片。
- 12 题测评采用确定性三维计分和五岗位加权；报告使用 ECharts SVG 雷达图，角色卡保存岗位、头像和私密昵称。
- 学生文本保存在 `Attempt.privateContent`，学习事件只保存引用、长度、模式和可汇总动作，不复制原文。
- 入口加 17 项主线用于单元进度；六项支线单独计数，不会提前触发结业。
- 完成条件可产生互动、任务和单元完成事件；单元完成事件只允许由最后一个主线互动触发。
