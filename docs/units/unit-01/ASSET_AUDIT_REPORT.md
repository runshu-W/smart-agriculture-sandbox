# 第一单元素材完整性审计报告

审计日期：2026-07-26  
审计范围：第一单元 24 个交互点、单元入口/结业、全局复用素材、代码引用与 `public/assets/` 实际文件。

## 1. 审计方法

逐项交叉核对 `UNIT_SPEC.md`、`ANIMATION_SPEC.md`、原始需求 `docs/unit_details/unit1.md`、两级素材清单/提示词、页面组件和磁盘文件。分类口径：

| 代码 | 判定 |
|---|---|
| C1 | 已由 CSS、SVG、Canvas、DOM 或图表代码正确实现，无需位图 |
| C2 | 已有素材，文件、清单、提示词、用途和路径一致 |
| C3 | 应生成但尚无文件 |
| C4 | 已有文件但漏登记或登记状态/路径错误 |
| C5 | 误当代码效果，独立实体外观过于简化，应拆成素材 |
| C6 | 应复用全局素材，但未引用或在单元内重复实现 |

审计原则：具有稳定、可辨识外观的角色、复杂机器、设备和教学样本使用素材；粒子、路径、流光、数据、扫描线、按钮、文字、图表和连续参数反馈继续由代码实现。

## 2. 磁盘与登记勾稽

- 审计前实际位图共 11 个：2 个全局、9 个第一单元；尺寸与格式检查通过。

- 复用矩阵声明“不另生成智慧农业设备”，与全局无人机 planned 条目及后续单元复用目标矛盾。

## 4. 本轮冻结的补齐清单

7. `G-CROP-DISEASE-01..03` 三张病害教学样本。

## 5. 明确不生成的视觉

- 无人机航线、喷洒粒子、收割遮罩、土壤数据流、指示灯脉冲、AI 扫描线。

## 6. 验收结论

审计前素材清单对“背景存在”与“交互视觉完整”混为一谈，导致复杂实体漏项。完成本报告冻结项、代码接入、路径自动勾稽和页面复核后，第一单元才可标记为视觉素材覆盖通过。外部故事素材不计为生成失败，但必须持续显示授权阻塞状态。
