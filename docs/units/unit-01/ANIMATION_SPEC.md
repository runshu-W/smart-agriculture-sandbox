# 第一单元动画规格

## 1. 动画技术分层

| 层级 | 技术 | 使用范围 |
|---|---|---|
| 页面与 UI | CSS / Web Animations | 面板进入、进度、按钮反馈、卡片翻转 |
| 场景交互 | DOM + SVG | 热点、摇柄、阀门、滑杆、仪表盘、路径 |
| 连续效果 | Canvas 2D | 稻粒、翻土、水滴、喷洒、数据粒子 |
| 视频 | HTML Video | 新农人纪实短片 |
| 预留 3D | Three.js 接口 | 后续确需自由镜头或模型检查的设备，不进入 M1 |

所有动画由交互状态驱动，不得用不可响应用户操作的整段装饰视频代替。

## 2. 全局转场

| 编号 | 转场 | 时长 | 行为 |
|---|---|---:|---|
| `U01-ANIM-ENTRY` | 单元入口进入大厅 | 600ms | 背景轻微推进，标题与农小智分两拍出现 |
| `U01-ANIM-HALL` | 场馆切换 | 500ms | 当前场景降低饱和并淡出，新场景横向揭示；减少动态模式仅交叉淡化 |
| `U01-ANIM-POD` | 体验舱开门 | 700ms | 舱门左右打开、环境光变色、工作台进入 |
| `U01-ANIM-COMPLETE` | 互动完成 | 450ms | 热点由高亮转完成勾，进度增加，农小智显示短反馈 |
| `U01-ANIM-UNIT-END` | 单元结业 | 1800ms | 勋章进入、柔和金色粒子、结果逐项出现 |

## 3. 农业三部曲

### 3.1 传统农业馆

#### 木犁与牛耕

- 热点激活：木犁描边在 220ms 内增强，点击后镜头只做 4% 推近。
- 演示循环：黄牛和农民沿短路径前进，犁头后方 Canvas 翻土粒子随速度出现，共 15 秒。
- 循环结束后停止新粒子，已有粒子在 600ms 内消散，再进入讲解。
- 降低动态模式保留位置变化，关闭粒子和镜头推进。

#### 手摇脱粒机（M1）

- 摇柄由中心轴和独立把手组成；Pointer Capture 保证拖出边界后仍可操作。
- 根据连续两次指针相对中心角度计算角速度，处理跨越 `-π/π` 的角度跳变。
- 角速度经低通平滑后映射到滚筒转速、轻微机身震动、机械声速率和稻粒生成率。
- 有效速度阈值：归一化速度 `>=0.22`；超过阈值才累计有效操作时间，停止超过 400ms 后暂停累计。
- 粒子只从出料口区域生成，数量与速度成正比；粒子采用金黄短椭圆，无阴影、无布局影响。
- 达到 10 秒时进度环闭合，稻粒短暂增多，摇柄在 500ms 内阻尼停下，然后进入讲解。
- 错误答案时答案区左右轻移 160ms，分步公式逐行出现；禁止强烈红色闪屏。
- 正确答案时出现绿色完成线和小范围丰收金粒子，800ms 后进入结果。
- 键盘模式：左右方向键模拟等速摇动，按住时持续累计；视觉和评分与指针操作一致。

#### 蓑衣斗笠与节气牌

- 蓑衣斗笠在 450ms 内从墙面向前平移并放大，节气牌使用 3D CSS 翻转。
- 农谚切换采用纵向卷动，不在图片中绘制文字。

### 3.2 现代农业馆

- 联合收割机：背景田地采用横向视差，收割区域用遮罩从金黄切换为短茬；左上数据由代码递增。
- 温室控制：温度/通风滑杆连续驱动作物色相、叶片展开度和数据值；不使用几个离散静态卡片冒充调节。
- 水肥一体化：阀门旋转后沿管线显示流动高光，根部水滴 Canvas 动画与节水对比数值同步出现。

### 3.3 智慧农业馆

- 无人机：沿 SVG 路径移动，喷洒锥形粒子只在航线上开启；细节参数是 DOM 数据层。
- 传感器：指示灯每 1.2 秒脉冲一次，连线流光到大屏，数据每 5 秒更新并有数值过渡。
- AI 识别：选择图片后显示扫描线 3 秒；结果按病害、程度、防治方案三步出现，明确为预设图片仿真。

## 4. 岗位体验中心

- 环形大厅使用 2.5D 背景和五个 DOM 热点，不构建不可维护的全 3D 大厅。
- 主播舱：倒计时环连续缩短，录音波形只展示音量可视化，不声称情绪识别。
- 农场运营舱：光照和温度值连续变化；全部达标后叶片在 500ms 内由偏黄变绿并展开。
- 品牌策划舱：提交后广告语以排版卡片生成，不把文字烘焙到背景图。
- 电商运营舱：订单状态按“待处理→核对→已发货”切换，步骤完成时显示简短勾选。
- 创业舱：项目卡选择后移入意向卡，理由文本由 DOM 排版。

## 5. 测评、角色卡和结业

- 题目切换 240ms，进度条只在确认答案后增加；返回修改不重复播放大型转场。
- 报告生成动画固定约 3 秒，但真实计算在服务端同步完成；若已返回数据，可提前结束至 1.2 秒最低展示时间。
- 岗位匹配雷达使用 ECharts；五岗位排序和百分比从数据层读取。
- 角色卡由头像、昵称、岗位和属性 DOM 组合，可打印/截图；不要求生成含个人文字的位图。

## 6. 支线

- 故事展柜点击后使用柔和聚光和卡片展开；视频知识提示由时间码触发 DOM 标注。
- 感悟卡和初印象便签使用真实文本组件；纸张纹理可复用，文字不得写入生成图片。
- 前后认知报告使用左右对比与连线，减少动态模式直接显示最终对比。

## 7. 音画同步

- 每条讲解保存音频路径、字幕文本和可选时间码；首版可先使用人工校准的句级时间码。
- 用户静音后字幕仍自动显示；重播只重复当前讲解，不重置已完成操作。
- 音频加载失败时显示“音频暂不可用”并继续字幕，不以浏览器自动朗读伪装已交付配音。

## 8. 动画验收

- M1 摇柄旋转、滚筒速度、粒子数量和有效计时具有同一速度来源。
- 任何反馈层不得遮住下一个操作按钮或农小智字幕。
- 1280x720、1440x900、1920x1080 下主交互对象保持完整。
- Canvas 首帧和操作后像素均非空，操作前后画面发生可检测变化。
- 降低动态模式下仍可理解因果、完成任务并获得相同分数。

## 9. M2-A 补充

- 入口邀请函：背景由远至近 3% 轻推；邀请函上下两层在 700ms 内展开，农小智从画面下缘进入。降低动态模式直接显示展开状态。
- 木犁牛耕：透明主体沿 62% 宽度田垄移动 15 秒；主体每 2.2 秒轻微起伏，Canvas 泥土只从犁头后方生成；实时耕作面积从 0 增至 3 亩。
- 节气经验：蓑衣斗笠从墙面向前平移放大；节气牌点击后执行 500ms `rotateY(180deg)`，农谚 DOM 文本随翻面切换；至少一次翻面后解锁讲解。
- 互动完成后显示柔和绿色完成反馈并返回第一单元地图；错误反馈不使用大面积红色或否定性标签。

## 10. 第一版本动画实现状态

- 现代馆已实现收割机横移与收割遮罩、温室连续参数驱动作物状态、阀门旋转与管线水滴流动。
- 智慧馆已实现 SVG 航线无人机与喷洒揭示、传感器连接和 5 秒数据更新、预设叶片的 3 秒扫描线与分步结果。
- 五岗位已实现麦克风录音状态、连续滑杆、广告语生成、订单状态流转和创业项目意向卡。
- 测评题目进度、3 秒报告生成、ECharts 雷达图、角色卡和结业勋章均由状态驱动。
- 支线已实现十展柜选择、可暂停的四节点媒体预览、感悟卡、便签展开/点赞和前后认知对比。
- 关键动画均提供 `prefers-reduced-motion` 路径；正式配音未交付时明确显示“音频暂不可用”。
