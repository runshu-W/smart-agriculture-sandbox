# 行业冲击直播场景 · 2026-09-10

设计标尺：摄影现场占桌面约65%，独立消息侧栏占约35%。主场景不加整体暗色遮罩，仅底部弹幕区域做渐暗。侧栏 #12251f，卡片 #1c3029，正文 #f1f5ec，次级文字 #adbbb0，快讯 #ffb280，通话 #8ed5ac。沿用平台中文无衬线字体。侧栏标题18–22px，正文14–16px，标签11–12px；8–12px圆角，14–20px间距。图标沿用lucide细描边（16–20px），按钮保留明确hover/focus。

既有标题、场景文案、六阶段、四观察区及完整事件文案保留。画面新增产品摄影缩略图；概念中的装饰性汉字标牌不写入真实素材，避免不必要标语。摄影底图不模拟口型；原语音仅用于张大叔来电，并提供完整字幕。声音默认关闭。

等待状态：消息栏用运营助理身份和观察提示；后续快讯、来电和群聊按原时序占用侧栏，已有事件持续可回看。全部动态数据绑定原场景状态，轨迹只展示当前已发生人数变化。手机按现场→消息→农小智纵向排列，不把正文遮到主播上。

验证目标：课堂入口→开始冲击→人数变化/来电/群聊→暂停恢复及刷新→点击回看并同步观察记录。对比概念与实际页面的构图、字体、颜色、素材裁切、间距、状态和手机适配。

## 视觉核对与实现说明

概念图：工作区 outputs/design/impact-concept.png（1536×1024，单独模块）；实际大屏截图：outputs/livestream-redesign/行业冲击-大屏全景.png（1920×1080，含原有课堂外框）。由于课堂导航、计时和到场面板需要保留，实际模块约1470px宽，采用紧凑高度；不把模块强行撑成概念图的独立1024px高。

| 对照点 | 实现与复核 |
|---|---|
| 主次布局 | 现场66% + 消息34%，新闻/来电/群聊在独立右侧栏；手机纵向排列 |
| 配色 | 保留深松绿工具栏、墨绿消息区、橙色快讯、浅绿通话和暖色摄影，无全图暗色遮罩 |
| 字体与密度 | 中文沿用平台字体；大屏标题22px、正文15px；为保留原课堂外框缩小概念中的字号/图高，完整文案可读 |
| 场景与素材 | 同一摄影场景包含主播、木台、瓜筐、田野和补光设备；产品与新闻分别独立生成，不裁切概念图；保留原农小智 |
| 消息层次 | 三种卡片使用统一圆角边线，新闻有配图、来电有状态与波形、群聊逐条出现；新消息数随实际出现条数变化 |
| 文案核对 | 完整手册新闻/瓜农/团队台词保持；保留产品名、教学情境、声音按钮、农小智提示。新增图像用途标注；移除过时“班级统计将在第三步接入”提示 |
| 可访问状态 | 保留原键盘可点按钮与模态回看、完整字幕、默认静音及减少动态样式 |
| 缺陷修复 | 修复暂停/结束/重新挂载时入场动画停在opacity0，事件和弹幕保持可见；手机人数改紧凑横条避免遮脸 |
