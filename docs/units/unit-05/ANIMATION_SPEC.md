# 第五单元动画与反馈规格

## 1. 全局节奏

- 单元地图沿“现在 → 未来”的上升时间轴组织，场景卡在解锁时由灰阶过渡到彩色并点亮路径。
- 场景进入 520ms 景深推近；主操作采用 180–360ms 明确反馈；仪式性合书、发布、结局允许 1.2–2.8s。
- `prefers-reduced-motion` 下移除循环漂浮、粒子和大幅位移，以淡入、进度条和即时终态替代，不移除步骤与反馈。
- 图片负责空间、人物和叙事环境；CSS/SVG/Canvas 负责光带、阶梯、图表、时间轴、粒子、描边和状态，不把图表烘焙进图片。

## 3. 转场与可访问性

- 地图到任务用共享场景图交叉淡入；任务完成后先展示结果和数据写入状态，再允许继续。
- 所有拖动均提供点击替代；播放器有可访问名称；颜色之外同时使用图形、文本和进度表达状态。
- 规划、信件和留言的保存按钮显示 `保存中/已保存/失败可重试`，不得无限转圈或用遮罩阻断按钮。
- 音频未提供时显示“配音待接入”，字幕始终可见；不伪造已播放语音。



## 课堂框架第一步
六阶段导航随服务器状态高亮；候场呼吸指示、准备成功反馈、暂停静止时钟、同步状态提示。切换使用轻量 CSS 淡入，遵循 reduced-motion。首步不播放尚未开发的行业冲击动画。大屏无控制台侧栏和学生名单。

## 行业冲击第二步
服务器保存独立冲击播放时钟；新闻 0.3 秒右滑，在线人数 2–10 秒按 3000/2500/1800/1200/800/400/200 节点插值下降，10 秒红色提示三次、背景变暗 20%；12 秒来电振动与铃声、随后接通配音；20 秒群聊、21.5 秒第二条消息；26 秒观察提示。暂停停止场景 CSS 动画和音频。reduced-motion 禁止滑动/闪烁，仍保留完整时序与数字变化。新闻、电话、群聊始终可回看，弹层有明确关闭按钮，遮罩点击不关闭。教师大屏默认静音，主动开启后播放。

## 课堂第三步
汇总页随教师操作同步显示；图表采用环形进度与水平条，数值来自记录，空值显示“暂无样本”。路径卡展开/阅读完成使用 0.2 秒状态变化、勾选与文字；reduced-motion 禁用过渡。农小智引导从观察到比较三条路径，不新增视频音频。
第三步视觉复核：大屏统计采用三列并排（模拟指数 / 持续观察比例 / TOP3），消除原纵排导致引导区域超出首屏的问题；路径卡统一顶端对齐，机会与风险完整展示，已通过首屏边界检查。

## 课堂第四步
身份徽标由运营助理切为核心运营负责人（淡入0.3秒）；情境升级显示新来电语音及字幕、团队对立留言。四决策卡选中抬升并勾选、确认提交后转个人报告；最后30秒倒计时红色呼吸，reduced-motion只变色。教师/大屏四项条形与耗时分布随记录更新，无装饰随机数。课中暂停即暂停计时与配音。

第四步视觉复核：投屏将角色身份、来电字幕、对立留言横排，四项统计与讨论引导完整进入 1080p 首屏。学生手机保持纵向情境与四选项布局，账号栏放至页尾避免遮挡确认按钮。个人报告分开呈现冲击和决策两段轨迹，只有 10 秒内的相邻实际操作点以虚线连接供阅读，长空白留空；两段不连线。

## 课堂第五步
三层同心圆按外/中/内逐层淡入，点击层级高亮且显示待确认标记；错误反馈轻微横向抖动并出现“再想想”，正确圆环绿色轮廓及勾选。全部答对后三环光晕依次亮起并显示农小智总结。暂停时停止交互与动画，计时沿用课堂阶段时钟。reduced-motion关闭入场、抖动和发光动画，保留文字/勾选反馈。汇总条平滑更新，不采用随机数。

第五步视觉复核：错误“再想想”反馈、三题完成后三圈绿色勾选与农小智总结均已浏览器验证。手机将事件选择放在同心圆前，减少来回滚动；1080p大屏压缩统计卡片间距，完整呈现底部总结。保存期间下一事件按钮暂不可点，避免吞掉快速点击。

## 剩余步骤六至八
地图三层区域可点添加，标签红黄切换、拖拽排序、保存状态与组内候选实时反馈；组内可查看和推选，展示支持缩放。地图3/7/2分钟自动推进、暂停冻结，不丢弃草稿。10秒投票计时与人数同步，结束后柱状图进入，三信号表随老师展示。均尊重reduced-motion，所有拖动提供按钮替代，错误可恢复，无静态假数据。

完成实现：地图同层拖动及上/下移，红黄优先级，自动3/7/2分钟子阶段，暂停冻结；投屏原生缩放与可滚动区域。投票结果条形宽度随真实比例变化，尊重减少动效设置。决策及投票最后10秒每秒合成轻提示；映射正确0.5秒、错误0.3秒合成音，默认关闭，用户手动开启，卸载后关闭音频上下文。

最终视觉QA：1920×1080地图和投票三信号首屏完整；390×844手机与1024×768平板触屏模拟无横向溢出。Chrome/Edge验证同层拖动、键盘替代、红黄切换、阶段自动推进、音频开关与实际倒计时合成音触发。
