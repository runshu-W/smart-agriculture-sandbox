# 第五单元需求规格

## 1. 单元边界

- 单元：第五单元「规划生涯 放飞梦想」
- 原始需求：`docs/unit_details/unit5.md`（573 行，开发前已完整核对）
- 概念图：`docs/references/unit5.png`，仅作为明亮农业科技、成长阶梯和梦想墙的构图参考，不拆取合成元素。
- 规模：21 个主线互动、4 个支线互动，共 25 个编号互动。
- 数据原则：成长回顾、岗位匹配和结局必须读取前四单元统一数据；不得使用随机分或硬编码装饰数字。
- 隐私原则：生涯规划全文、未来信件、自由宣言和留言正文默认仅学生本人可见；教师只见完成率、公开范围和匿名聚合。
- 协作边界：梦想墙首版采用种子班级数据 + 共享设备/异步互动，不实现 WebSocket 实时多人。
- 结局安全：三种结局都是成长起点，不使用“失败者”、排名或负向标签。
- 原题边界：支线未来推演要求 5 个决策点，但原文只提供 2028 年一道示例题。首版保留 5 节点时间轴，完整实现该原题，其余节点标记“课程题干待补充”，不擅自编题。

## 4. 解锁与数据驱动

- 主线按表格顺序解锁；五个任务组完成上一组后开启下一组。
- 两条支线各自独立顺序，至少完成对应主线场景入口后可进入，不阻塞主线结局。
- 第五单元完成状态以 `u05-ending-01-future` 完成为准；结局值由五单元已完成互动比例、能力当前值和规划完整度构成，规则版本化并展示来源。
- 岗位匹配使用第一单元职业偏好、第二单元自我认知/韧性、第三单元协作、第四单元学习能力和各岗位任务行为；任何分数均可展开证据。
- 所有互动调用统一尝试与完成 API，写入 `ATTEMPT_STARTED`、`INTERACTION_COMPLETED`、`PROGRESS_UPDATED`；进入单元写 `UNIT_ENTERED`。
- 自由文本只在私密内容区保存引用；公共梦想墙只显示学生主动选择公开的摘要。首版不做自动情感诊断。

## 5. 验收

- 25 个编号互动均可运行，所有题干和选项与原始需求逐字一致。
- 阶梯、岔路、雷达/成长树、动态回放、对比镜、匹配分析、五步规划、梦想墙、三结局、预言书和时光信件均保留操作过程与动画。
- 五岗位匹配、成长曲线和结局来自统一数据层；没有随机成绩或硬编码装饰报告。
- 学生能回看本人规划和信件；教师只见授权班级聚合，不见私密正文。
- 缺失的 4 个未来决策题可见标注且不计错，不擅自补题。

## 2026-09-09 课堂互动改造第一步

本次用户授权实现教师建课与控场、学生候场、大屏同步，覆盖旧规格不默认实时协作的边界。仅建设六阶段课堂框架；行业冲击、决策、映射、协作、投票具体操作后续开发，不标记为已完成。保留原有自主闯关。

教师可为授权班级创建正式/演练课堂，同班同时仅一个未结束课堂；查看到场和准备情况，开始、暂停、继续、重置当前计时、切换阶段及结束。六阶段默认时长 7/2/6/8/12/5 分钟。到时等待老师推进，不自动切换。重置计时不删除学习记录。阶段切换重新开始该阶段计时，暂停状态下切换仍保持暂停。结束后不可继续控制，但可回看。

学生直接从课堂入口加入所属班级，不受自主闯关前置进度限制；只能观看当前阶段，可标记准备就绪。跨班、跨角色访问被拒绝。课堂状态持久化，刷新/短断网重新连接后恢复，离线时显示连接提示且禁用控制。独立大屏展示阶段、计时、准备与到场汇总，不传输学生名单。

实时状态通过 SSE 更新，数据库为权威来源，命令携带状态版本以避免重复推进。加入/准备就绪接入 LearningEvent；教师控制留审计记录，正式与演练标记单独保存，不完成自主关卡或增加能力分。

验收：一个教师、至少两个独立学生会话与大屏；验证候场、准备、开始、暂停、继续、计时重置、六阶段切换、刷新、断线恢复、到场变化和权限。

第一步验证结果（2026-09-09）：上述多会话验收通过；36 项单元测试、4 项原流程浏览器回归测试、类型检查、生产构建和素材审计通过。lint 为 0 错误，存在原有 prisma.config.ts 未使用变量警告。联调使用独立数据库，未重置用户原数据库；25 人并发验收留在第八步。Windows 启动脚本已增加 db:generate 和 db:deploy，不执行 seed。LiveLesson_one_open_per_class 为迁移中手写的部分唯一索引，后续迁移必须保留同班仅一节开放课堂的约束。

## 课堂互动第二步：行业冲击情境（2026-09-09）

学生可用鼠标、键盘、触摸查看四个事件，记录查看顺序、关注区域、累计停留和观察后首次操作等待时间，本地持久缓存并补发统一事件，不采集真实视线、不推断心理状态。第三步制作班级统计与路径参考，本次不伪造班级情绪均值或分布。声音需各设备主动开启；始终有字幕，可静音，音频无法播放时明确提示。

## 课堂第三步：冲击统计与路径参考（2026-09-09）
教师在冲击 26 秒情境结束后点击“查看班级数据”，冻结冲击观察时钟、结束采集并通知学生补传与确认；投屏展示聚合，教师可查看个人明细。记录补传后统计自动更新，缺失与尚未上传不填零、不使用手册示例数值。可返回情境回看但不重开采集；未显式汇总就离开第一阶段/结束课堂时亦关闭采集。
统计规则：以本次课堂截止前已加入成员为参与范围，完整上传确认人数为主要统计分母；关注人数按人去重、停留时长合并重叠区间。观察起点为 max(26000ms, 个人加入时冲击进度)，首次点击等待 >5 秒为持续观察；窗口不足 5 秒且无点击单列样本不足，尚未上传不视作未操作。“情绪波动指数（教学模拟）”是可解释的操作代理值：1 + min(3, 1秒内重复点击次数×0.5) + min(3, 跨事件切换次数×0.3) + min(3, 等待秒数/5)，截断 1–10；不代表真实心理状态，不调整分数或人格标签，不用随机分布。不同设备的重复区间合并；公式、分母、等待下界均在明细展示。
第二阶段保留转型/坚守/升级内容，新增可阅读的机会、风险和观察问题（教学补充文案，非保证收益）。学生打开后明确标记已阅读，三项分别保存、刷新恢复；教师/大屏看到完成计数，名单仅教师。为第四步决策保留 ownPathsReady 条件，本次不提前完成四选项决策；原有自主闯关入口不变。
验收：真实记录汇总、空样本/缺失/晚加入/区间重叠、停止采集补传、学生看不到他人明细、三项阅读去重与恢复、跨班权限、正式演练隔离、1920×1080 大屏和手机。

第三步验收（2026-09-09）：教师、两名独立学生会话及大屏通过统计汇总、缺失补传、个人明细隔离、结束后回看入口、三路径阅读保存、重复标记去重、刷新恢复、第二阶段后补读提示和跨班权限联调。统计测试包含空样本、未上传不计入、5 秒边界、晚加入、停留区间合并、无点击下界、分母与确定性公式。前两步完整浏览器流程回归通过。46 项单元测试及素材审计通过。1920×1080 下关键统计、三路径、阅读进度和农小智引导均在首屏；390px 手机无横向溢出。使用独立测试数据库，未重置用户原有数据库；测试中仅对新建测试课堂调整冲击时钟以验证统计边界，真实 26 秒播放另有回归测试。下一步接入四选项角色决策及个人分析报告，未提前宣称已完成。

## 课堂第四步：角色决策与报告（2026-09-09）
第三阶段将运营助理升级为核心运营负责人，呈现张大叔新来电与团队两条对立留言。教师“发起3分钟决策”单独启动服务器权威180秒决策时钟，与6分钟阶段时钟区分；暂停/继续同时作用于两者，阶段重置不重开决策。离开第三阶段或结束课堂会关闭决策，未确认者记录“未作答”，不代选 A–D。到时自动结算（在线推送触发；全部离线后首次恢复时立即补结算），迟到者仅享剩余时间。
