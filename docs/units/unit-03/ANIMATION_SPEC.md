# 第三单元动画与反馈规格

## 1. 通用时序

- 场景进入：背景 520ms 推近、交互台 360ms 上浮；减少动态模式改为淡入。
- 选择反馈：120-220ms 按压，300-600ms 数值/表情/分支变化；反馈完成前不允许重复提交。
- 动画序列提供播放、暂停、重播和字幕；静音仅关闭提示音，不隐藏字幕。
- 状态动画由学习操作触发，禁止无限装饰动画占用主视线。

## 3. 性能与可访问性

- WebP 背景使用响应式尺寸；透明人物和故事板延迟加载，首屏只预载当前场景。
- CSS 动画只改变 `transform`、`opacity` 或小范围 SVG 属性；大图不做滤镜级持续动画。
- `prefers-reduced-motion` 下取消推镜、飞行和 3D 翻转，保留顺序、状态和数值结果。
- 拖放、翻卡、时间线、播放控制均提供键盘等价操作和可读标签。
