# 第三单元需求规格

## 1. 单元边界

- 单元：第三单元「和谐交往 快乐生活」
- 需求真相源：`docs/unit_details/unit3.md`
- 核心 NPC：农小智（沟通教练）
- 素养：公共参与、健全人格
- 主线：职场沟通模拟、丰收节协作、矛盾调解、感恩墙、和谐之门，共 14 个互动点。
- 支线：职场人际关系图谱、同理心训练营，共 6 个互动点。
- 小组机制首版采用共享设备、组长提交和异步汇总，不要求实时多人在线。
- 文档只明确沟通风格分析第 1 题、同理心角色 A 第 1 轮；实现不得擅自补写其余题目或台词，以已明确内容形成完整可提交互动，并保留后续课程内容扩展位。

## 4. 原文题目门禁

实现中的问题和选项必须逐字来自需求文档：

- 与上级：`你的直播电商项目进展顺利，但物流成本比预算超了 15%。向王总汇报时，你会怎么说？`
- 与同事第一问：`作为协调人，你的第一句话会说什么？`
- 与同事第二问：`听完大家的情况后，以下哪个分工方案你最支持？`
- 客诉：`看到客户的愤怒消息后，你的第一条回复是？`
- 队长：`作为队长，你发现团队中有一个人比较沉默，不太参与讨论。你会怎么做？`
- 延迟：`活动策划组因为方案意见不统一，进度卡在了 60%。作为团队，你会怎么处理？`
- 冲突：`双方陈述完毕后，作为团队，你们选择：`
- 欺凌：`面对被孤立的情况，你会怎么做？`
- Case #001 的小赵视角继续逐字使用上题；原需求未提供同事与调解人视角题，本轮按产品修复要求补充两个明确标记为“情境补充”的视角题，不替换或冒充教材原题。
- 诱惑：`面对供应商的“合作”邀请，你会怎么做？`
- 误解：`你发现账目错误其实是另一位成员操作失误导致的。你会怎么做？`
- 感恩：`请选择你要感谢的人，并写下你想对 TA 说的话。（至少 50 字）`
- 关系：`观察你的关系花园，你觉得哪段关系最需要你花更多心思去经营？`
- 风格：`团队讨论时出现意见分歧，你通常会？`
- 改善：`写下一个你想改善的具体关系和行动计划。`
- 角色：`请选择你要扮演的角色：`
- 演绎：`你的回应是？`
- 复盘：`通过今天的角色扮演，你最大的感悟是什么？`

完整选项与逐项点评在实现数据常量中保持需求原文，并由测试校验关键句，禁止自行改写。

## 5. 解锁、评分与隐私

- 主线按表格顺序解锁；支线在单元开放后可独立体验，支线不阻塞结业。
- 选择题不把心理、人际风格标记为人格优劣；分数衡量任务完成和策略覆盖。
- 感恩原文、真实姓名、关系计划仅保存到 `privateContent`，教师看板只汇总对象类别、长度、完成率和策略分布。
- 所有互动使用统一 `Attempt / Progress / LearningEvent / AbilitySnapshot` 数据链；完成后学生进度和教师聚合立即从数据库读取。
