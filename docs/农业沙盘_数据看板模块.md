# 智慧农业职场闯关虚拟仿真沙盘

## ——数据看板设计技术对接文档

## 数据源说明

- 🟢 **虚拟仿真沙盘：** 闯关行为数据（决策路径、情绪稳定性、任务完成率、协作行为等）
- 🔵 **学习通：** 课前心理素养微测评、职业倾向问卷、课中互动数据
- 🟡 **国家职业教育智慧教育平台：** 课前预习数据、思政资源学习完成度
- 🟠 **教师上传接口：** 教师手动导入外部平台数据（学习通导出、国家职业教育智慧教育平台导出等）

## 关键要求

1. 教师端每个图表左上角需标注数据来源标签（用颜色区分：沙盘 🟢 / 学习通 🔵 / 国家职业教育智慧教育平台 🟡 / 教师上传 🟠）。
2. 教师端需提供数据上传接口（Excel 批量导入），用于接入学习通和国家职业教育智慧教育平台的外部数据。
3. 所有板块需支持“入学基线 vs 当前值”的增值对比。
4. 数据可交叉使用，同一数据可支撑多个板块（详见数据交叉关系说明）。

# 二、学生端看板设计

学生端供学生各自查看个人数据，包含四个模块。

## 2.1 我的素养画像

- **图表类型：** 双层雷达图
- **展示维度：** 五维素养——政治认同、职业精神、法治观念、健全人格、公共参与
- **双层叠加：** 入学基线值（内圈虚线）vs 当前值（外圈实线）
- **交互：** 鼠标悬停可查看具体分值

## 2.2 我的成长曲线

- **图表类型：** 多折线图
- **X 轴：** 课次（第 1 课～第 15 课）
- **Y 轴：** 各维度得分
- **展示内容：** 五个维度从入学到当前的增值趋势
- **交互：** 可切换维度显示/隐藏

## 2.3 闯关进度

- **图表类型：** 进度条 + 徽章墙
- **展示内容：** 已完成关卡数/总关卡数、已获得徽章图标、当前关卡状态（未开始/进行中/已完成）
- **徽章设计：** 每个关卡/单元完成后解锁对应徽章（如“情绪管理达人”“抗压勇士”“合规卫士”等）

## 2.4 云禾英雄榜

- **图表类型：** 排行榜列表（表格形式）
- **排行维度（可切换 Tab）：**
  - 综合素养分排名
  - 关卡完成速度排名
  - 徽章收集数量排名
- **隐私保护：** 支持匿名模式（显示昵称而非真实姓名）
- **展示范围：** 仅展示本人排名 + 前后各 2 名（不做全员排名展示，避免压力）

# 三、教师端看板设计

教师端供授课团队使用，可查看全班 25 人的数据。顶部设置通用功能栏。

## 3.0 顶部通用功能栏

| 功能 | 说明 |
|---|---|
| 数据源标注 | 每个图表左上角用颜色标签标注数据来源（沙盘 🟢 / 学习通 🔵 / 国家职业教育智慧教育平台 🟡 / 教师上传 🟠） |
| 基线设置 | 支持导入或手动录入入学基线数据（学期初采集的测评数据） |
| 数据上传接口 | Excel 批量上传入口，支持导入学习通导出数据、国家职业教育智慧教育平台导出数据 |
| 时间筛选 | 按课次（第 X 课）/ 周次 / 月次 / 学期筛选数据范围 |
| 导出报告 | 一键生成 PDF 版班级成长报告（含三个板块全部图表） |
| 学生筛选 | 可查看全班汇总数据，也可筛选单个学生查看详细数据 |

# 五、技术实现建议

## 5.1 数据上传要求

- 支持 Excel（.xlsx/.csv）文件上传。
- 预置模板下载：教师可下载标准模板，按模板格式填入数据后上传。
- 模板字段说明：学生姓名/学号、测评维度、得分、测评时间、数据来源。
- 上传后自动校验数据格式，异常数据标红提示。

## 5.2 动态图表要求

- 所有图表支持鼠标悬停查看具体数值
- 支持时间范围筛选
- 折线图/柱状图支持导出为图片

## 5.3 权限设计

- **学生端：** 仅可查看个人数据 + 班级排行榜（脱敏，不显示其他人）。
- **教师端：** 可查看全班数据 + 个人数据 + 数据上传 + 报告导出。
