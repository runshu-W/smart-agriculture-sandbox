# 登录分流、学生首页与五单元学习地图规格

## 1. 页面边界

- `/` 不展示公共业务首页，只按会话状态分流：未登录进入 `/student-login`，学生进入 `/student`，教师进入 `/teacher/dashboard`。
- `/student-login` 是独立学生登录入口，只接受学生账号；`/teacher-login` 是独立教师登录入口，只接受教师账号。
- `/student` 是学生登录后的项目首页和五单元学习地图，展示项目定位、课程结构、状态、进度和继续入口。
- `/teacher/dashboard` 是教师登录后的管理后台总览；学生端导航不得出现教师管理入口，教师后台不得混入学生学习入口。
- `/student/unit-01` 是第一单元内部任务地图，负责第一单元主线的继续逻辑。

## 2. 学生项目首页

- 首屏展示项目名称、项目简介、农小智和项目级智慧农业全景；不使用传统农业馆或脱粒机作为主背景。
- 提供五单元学习、成长档案和当前任务入口，不提供教师后台入口。
- 主按钮从数据库读取学生进度，按已发布互动顺序跳转到首个未完成互动；当前批次全部完成后返回第一单元任务地图。
- 农小智使用确定性引导文案，不提供自由对话入口。
- 学生端和教师端分别提供常驻退出登录按钮，退出后返回各自登录入口。

## 3. 五单元学习地图

| 单元 | 名称 | 简介 | 首版开放 |
|---|---|---|---|
| 01 | 时代导航 生涯筑梦 | 穿越农业三个时代，体验五类岗位并建立初始职业定位。 | 是 |
| 02 | 认识自我 健康成长 | 认识兴趣、性格和能力，在挫折与情绪任务中发展心理韧性。 | 否 |
| 03 | 和谐交往 快乐生活 | 在沟通、协作与矛盾调解中建立健康的职场关系。 | 否 |
| 04 | 学会学习 终身受益 | 掌握学习方法与数字工具，形成持续成长的学习力。 | 否 |
| 05 | 规划生涯 放飞梦想 | 回顾成长证据，完成岗位匹配与个人生涯规划。 | 否 |

状态计算：未发布为“未开放”；已发布且无任何进度为“未开始”；存在未完成或部分完成互动为“进行中”；完成单元规定互动后为“已完成”。进度必须由统一 `Progress` 数据计算。

## 4. 视觉与素材

- 首页背景使用全局智慧农业项目全景，呈现生产、数字技术、职业学习三个层次，不绘制界面文字。
- 农小智复用 `G-CHAR-NXZ-GUIDE-01`，不生成首页专属版本。
- 五单元使用代码生成的编号、状态、进度和图标；后四单元开发前不提前生成单元封面。
