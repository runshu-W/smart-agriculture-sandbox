# 教师端删除功能审计与更新

## 审计结论

2026-09-14 检查页面与 API：班级管理只有归档（PATCH），导入批次只有上传和确认导入，两个页面均缺少删除入口，后端也没有相应 DELETE 接口。用户反馈准确。

## 最终行为

- 班级管理增加“删除班级”，适用于正常与已归档班级。需输入完整班级名称确认；存在未结束课堂时返回提示，必须先结束课堂。
- 删除班级会永久删除班级、师生关联、班级课堂与会话/作答/事件、班级指标、导入批次和明细。学生账号、个人 Progress/ScoreSnapshot 汇总和其他班级保留。所有任课教师都会失去该班级；如需保留完整教学记录，应归档。
- 导入批次增加“删除记录”，覆盖错误、待确认和已导入状态。按整个批次删除全部明细，支持清理已归档班级的历史批次；上传目标仍只显示未归档班级。
- 删除导入记录不会撤销导入：学生账号、成员关系和学习指标保留。指标的批次外键置空。相同文件可再次上传，但学生账号仍会查重，重复指标仍需确认覆盖。
- 两种删除均验证任课权限；删除和审计日志在同一事务中完成。班级删除采用 Serializable 隔离级别，审计记录不随班级删除。
- 删除最后一个班级后显示空状态和成功提示。修正班级管理手机端新建表单被横向挤压的问题。
- 使用现有外键级联与 SetNull 规则，无新增数据库迁移。
