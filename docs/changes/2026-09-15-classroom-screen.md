# 大屏控制与学生课堂列表优化

- 教师点击“打开大屏”后，右侧保留完整授课节奏控制：开始、暂停/继续、发起角色决策、地图与投票、阶段切换、计时重置、结束课堂。大屏按钮走教师 PATCH 接口，沿用权限校验、版本冲突保护和操作确认。
- 大屏保留班级汇总展示，不显示教师端学生姓名列表。修正大屏角色决策布局，使场景内容与控制栏并排；窄屏时控制栏排列在场景前。
- 学生课堂入口只列出未结束课堂。服务端在查询与分页前过滤 ENDED，客户端同时隐藏“最近结束的课堂”，包括自动刷新后和无当前课堂的等待状态。教师端历史课堂保留，历史教学记录未删除。
- 无数据库迁移。

验证：89 个测试通过，typecheck、build 通过；lint 无错误，保留 prisma.config.ts 原有未使用变量警告。独立临时数据库 + Chrome 验证了实际打开大屏、右侧控制、发起决策、暂停/继续与教师台同步、下一阶段、浏览器全屏、手机布局、学生 API/UI 与结束课堂后的自动刷新、教师历史列表、学生越权拒绝。
