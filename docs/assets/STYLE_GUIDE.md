# 智慧农业沙盘角色与美术风格规范

## 1. 视觉定位

- 面向中职一年级学生，整体应明亮、可信、具有农业现场感和适度科技感。
- 参考 `docs/references/` 概念图的空间层次、柔和日光、3D 卡通角色与写实设备结合方式，但不直接切取带文字的合成图。
- 采用高质量 2.5D 为主：无文字背景图负责空间氛围，透明角色与设备负责交互层，路径、热点、粒子、数据和反馈由前端代码驱动。
- 不以全屏深蓝科技界面替代农业现场。每个场景必须能看出明确的农业对象、时代或岗位。

## 2. 色彩系统

| 用途 | 色值 | 说明 |
|---|---|---|
| 品牌农业绿 | `#168A58` | 主操作、完成状态、农小智服装 |
| 深林绿 | `#0D5E45` | 标题、深色文本、重要描边 |
| 科技蓝 | `#2377B7` | 数据、智慧设备、信息状态 |
| 丰收金 | `#E5A82E` | 奖励、传统农业、重点提示 |
| 警示红 | `#D94C45` | 错误和风险，不作为装饰主色 |
| 雾白 | `#F5F8F6` | 页面底色和浅色面板 |
| 墨色 | `#15231F` | 正文和高对比信息 |

同一屏应至少包含农业绿、一个冷色信息色和一个暖色强调色，避免只使用单一绿色渐变。

## 3. 农小智规范

- 固定识别元素：白色圆润机器人脸、绿色叶片标识棒球帽、绿色科技夹克、智能耳机、大号绿色眼睛。
- 头身比例约 1:1.7，四肢短而灵活，表情友好但不过度幼儿化。
- 首批只制作 `idle`、`guide`、`encourage` 三个全身姿态和对应头像裁切；其他姿态按单元实际需要补充。
- 所有姿态保持帽子、耳机、夹克结构、眼睛颜色和身体比例一致，不重新设计角色。
- 对话框和字幕由前端绘制，角色图片内不得出现文字、气泡或光效。

## 4. 五岗位角色规范

- 五个岗位分别建立男性、女性标准形象，共 10 个基础角色；首批只定义服装、配色、道具和正面/四分之三视角，不生成所有动作。
- 助农电商主播：绿色围裙或轻户外马甲，手机稳定器/农产品篮。
- 智慧农场运营师：蓝灰功能夹克，平板电脑/传感器终端。
- 农产品品牌策划师：白色衬衫配暖橙工作马甲，设计板/包装样品。
- 乡村电商运营官：深蓝或紫灰商务休闲装，笔记本电脑/订单终端。
- 新农人创业家：墨绿简洁夹克，数据平板/项目文件夹。
- 角色年龄观感 17-22 岁，符合中职学生代入感；不得使用知名人物或品牌标志。

## 5. 场景与构图

- 运行场景以 16:9 为主，背景图不得包含按钮、标题、标签、对话框或不可交互的假 UI。
- 核心交互对象需留出完整轮廓和安全边距；桌面主视口中不得被固定导航遮挡。
- 传统农业使用自然土黄、稻草金和低饱和绿色；现代农业增加机械蓝；智慧农业使用清透绿色、科技蓝和真实作物色。
- 交互对象高亮、点击提示、进度环和结果反馈由代码叠加，保证状态可读和数据可变。

## 6. 动效原则

- 动画必须服务于因果：学生操作应直接改变设备速度、作物状态、数据或角色反馈。
- 页面转场 300-700ms；局部反馈 120-300ms；讲解演示按需求时间执行，不用装饰动画拖延操作。
- 允许降低粒子密度和阴影质量，但不得移除拖拽、滑杆、分支或结果反馈。
- 支持 `prefers-reduced-motion`：减少镜头位移和粒子，保留必要状态变化。

## 7. UI 与可访问性

- 功能面板圆角不超过 8px，避免卡片内再嵌套装饰卡片。
- 工具类按钮优先使用 Lucide 图标并提供 tooltip；主要命令使用图标加短文本。
- 字号不随视口宽度缩放；按钮和数值控件设置稳定尺寸，动态内容不得引起布局跳动。
- 拖拽、滑杆和排序必须提供键盘等价操作；讲解必须有字幕、暂停、重播和静音入口。

## 8. 素材验收

- 场景图：无文字、无水印、无假 UI、主体不被裁切，适配 16:9 裁切。
- 透明 PNG：具有 alpha 通道，四角透明，白底/深底/棋盘格均无背景色毛边。
- 角色：与标准角色锚点在脸型、比例、服装和配色上保持一致。
- 所有生成素材记录提示词、用途、规格、路径、版本、状态和复用范围。
